# mewc/homebrew-tap

```sh
brew install --cask mewc/tap/input-stats
```

Casks:

- **input-stats** — [Input Stats](https://input-stats.drummerduck.com), a menu-bar counter for keystrokes, clicks, scroll and pointer distance. Counts only, never what you type.

## Bumping a cask after a release

```sh
./bump.sh input-stats 0.2.3
```
